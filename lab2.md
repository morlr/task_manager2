# Звіт до лабораторної роботи №2
**Тема:** Виведення динамічного контенту. Створення базової HTML-структури сайту та інтеграція PHP-змінних одразу у розмітку.

## 1. Фрагмент коду (index.php)

Нижче наведено структуру оголошення PHP-змінних та їх виведення в HTML-теги за допомогою альтернативного синтаксису:

```php
<?php

\$appName = "Task Manager";
\$taskTitle = "Вивчити основи PHP та інтеграцію з HTML5";
\$taskTimeEstimate = 3; // ціле число
?>

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title><?= \$appName ?></title>
</head>
<body>

    <header>
        <h1><?= \$appName ?></h1>
    </header>

    <main>
        <h2>Поточне тестове завдання:</h2>
        <ul>
            <li><strong>Назва таска:</strong> <?= \$taskTitle ?></li>
            <li><strong>Очікуваний час виконання:</strong> <?= \$taskTimeEstimate ?> год.</li>
        </ul>
    </main>

</body>
</html>
```
## 2. Відповіді на контрольні запитання

### 1. Що таке динамічна типізація і як вона працює в PHP?
**Динамічна типізація** означає, що розробнику не потрібно вручную вказувати тип даних (наприклад, `int` чи `string`) при створенні змінної. PHP визначає тип автоматично в момент присвоєння значення. Тип змінної також може динамічно змінюватися під час виконання скрипту залежно від контексту (наприклад, якщо до числа додати рядок, воно може автоматично конвертуватися в рядок).

### 2. Як правильно розпочати і закрити блок з PHP-кодом всередині HTML-документа?
Стандартний блок PHP відкривається за допомогою тегу `<?php` і закривається тегом `?>`. Усе, що знаходиться всередині, інтерпретується сервером як PHP-код, а все, що поза ними — виводиться в браузер як звичайний HTML-код або текст.

### 3. В чому різниця між записами `<?php echo $var; ?>` та `<?= $var ?>`?
* `<?php echo $var; ?>` — це повний класичний запис команди виведення даних на екран.
* `<?= $var ?>` — це **альтернативний (короткий) синтаксис** (short echo tag). Він робить абсолютно те саме, але використовується для чистоти коду, коли потрібно швидко вбудувати значення однієї змінної всередину HTML-тегу.

### 4. Які основні (скалярні) типи даних підтримує PHP? Наведіть приклади.
PHP підтримує 4 основні скалярні типи даних:
* **Рядок (String):** `$name = "Антошко";`
* **Ціле число (Integer):** `$hours = 3;`
* **Число з плаваючою крапкою (Float):** `$rating = 4.8;`
* **Логічний тип (Boolean):** `$isDone = false;`

### 5. Що буде виведено в браузері, якщо користувач відкриє файл .html, всередині якого буде вбудовано `<?php echo "Test"; ?>` без налаштувань сервера? Поясніть чому.
Код `<?php echo "Test"; ?>` **не виконається**. Браузер або відобразить порожню сторінку (сприйнявши PHP-тег як невідомий HTML-тег і приховавши його), або при перегляді вихідного коду (Ctrl+U) ми побачимо цей тег у сирому вигляді. 
* **Причина:** Веб-сервер обробляє як PHP тільки файли з розширенням `.php`. Файли `.html` сервер віддає браузеру без змін, а браузери не вміють виконувати серверний PHP-код.
